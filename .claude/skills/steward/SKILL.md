# Steward

This repository follows the Morrison-Lab steward rules for pull requests.
Read them before acting on a pull request event:
[`skills/steward/SKILL.md` in Morrison-Lab/ai-config](https://github.com/Morrison-Lab/ai-config/blob/main/skills/steward/SKILL.md).
With the `ai-config@Morrison-Lab` plugin loaded,
the same rules are available as the `steward` skill.

The copy in ai-config is the one to edit;
this file only points to it.
